# Kolibri patterns applicable to the tutor

Source inspection used the existing local Kolibri checkout at commit `da32925bce3cd216c4c5c0ecb7429314926f50c5`. The patterns in the right-hand column are proposals for this project.

| Area | Verified behavior, purpose and limits | MVP design |
| --- | --- | --- |
| Offline deployment and constraints | Kolibri can serve over a local network from a PC or Raspberry Pi without internet. A browser client still needs access to that host. There is also a standalone Android app. Video content consumes significantly more storage than HTML documents and exercises. [FAQ](https://kolibri.readthedocs.io/en/latest/faq.html) · [Android installation](https://kolibri.readthedocs.io/en/latest/install/android.html) · [Raspberry Pi](https://kolibri.readthedocs.io/en/latest/install/raspberry_pi.html) | One small pack lives on the phone after initial acquisition. Validate on a physical Android in airplane mode, including reopening the browser with the remote server unreachable. |
| Content organization | `ContentNode`, `AssessmentMetaData`, `File` and `LocalFile` represent the curriculum tree, exercise metadata and on-device asset availability. The metadata database for a channel can be exchanged separately from assets. [Content models](https://github.com/learningequality/kolibri/blob/da32925bce3cd216c4c5c0ecb7429314926f50c5/kolibri/core/content/models.py) · [Channel docs](https://kolibri.readthedocs.io/en/latest/manage/resources.html) | Store versioned concept and item IDs and original Tamil text/visuals in a validated manifest. Keep origin bytes small with one narrow pack. |
| Content import and persistence | `ChannelImport.import_channel_data` transactionally imports source records into the destination DB. Separate content import and checksum-addressed local assets allow selected files to move by network or disk and help track what is playable. [Channel import code](https://github.com/learningequality/kolibri/blob/da32925bce3cd216c4c5c0ecb7429314926f50c5/kolibri/core/content/utils/channel_import.py#L942) · [Content implementation](https://kolibri-dev.readthedocs.io/en/latest/backend_architecture/content/implementation.html) | Activate whole packs after successful cache validation. Keep a previous usable pack on update failure. The browser's cache eviction policy still applies. |
| Exercises and progress | Perseus scoring is performed in the frontend. `AttemptLog` tracks hints and correctness, `MasteryLog` retains assessment criterion, and content logs distinguish sessions from summaries. Recent correct answers can determine completion. [Scoring source](https://github.com/learningequality/kolibri/blob/da32925bce3cd216c4c5c0ecb7429314926f50c5/kolibri/plugins/perseus_viewer/frontend/scoring.js) · [Logger source](https://github.com/learningequality/kolibri/blob/da32925bce3cd216c4c5c0ecb7429314926f50c5/kolibri/core/logger/models.py) · [Learner guide](https://kolibri.readthedocs.io/en/latest/learn.html) | Score in JS and derive concept state from local attempts. Keep hints, exposures and follow-up proof distinct. Skip broad interaction telemetry. |
| Profile access and coaching | `FacilityUser`, `Role` and `Membership` scope access, and coaches can inspect assigned learners and groups. [Auth source](https://github.com/learningequality/kolibri/blob/da32925bce3cd216c4c5c0ecb7429314926f50c5/kolibri/core/auth/models.py) · [Coach guide](https://kolibri.readthedocs.io/en/latest/coach/index.html) | Keep on-device synthetic profiles isolated. Adult view reads the selected learner after a deliberate handoff. |
| Local data and synchronization | SQLite enables local deployments. Morango supports scoped facility and user replication with certificates and staged transfers between instances. [Database options](https://github.com/learningequality/kolibri/blob/da32925bce3cd216c4c5c0ecb7429314926f50c5/kolibri/utils/options.py#L506) · [Facility synchronization](https://kolibri-dev.readthedocs.io/en/latest/backend_architecture/facility_syncing/) | Store events in IndexedDB, send idempotent batches and retain local evidence. Full peer replication and multi-device merge are deferred. |
